# 07 AI 势力、战斗与占领

用户需求原文对应:"AI 势力用简化模型跑,不做全模拟:一个实力值随时间增长,按规则扩张到相邻星球,只在玩家真的抵达时才实例化成基地。三种性格要有真实的行为差异——贸易型主动开航线不主动打、扩张型持续占星球会撞上你、封闭型守一颗星球但科技高。占领的收益必须具体:拿到它的独有资源 + 它的一条科技分支,不能是加个数值。"

本文档把上述需求落成公式、参数表、行为脚本与可测断言。

## 势力沙盘模型(全局,每星图刻 = 1 游戏时结算)

每个势力的全部状态:

```
Faction {
  personality: 贸易型 | 扩张型 | 封闭型
  P: 实力值(float)
  T: 科技等级(float,决定实例化基地的建筑层级与防御质量)
  credits: 金库
  heldBodies: 星体列表(含每星体防御值 D 与独有资源产能)
  attitude: 对玩家态度 -100..+100
  stance: 和平 | 通商 | 紧张 | 战争
}
```

### 成长与扩张(公式,初始值)

- 实力成长:`P += 1.2 × growthMult × heldBodies数^0.7`(每星图刻)。
- 科技成长:`T += 0.001 × techMult`(每星图刻)。T 决定懒实例化基地的建筑层级:`层级 = clamp(floor(T), 1, 4)`;静默会额外取"不低于玩家当前最高解锁层级"。
- 星体防御值:`D = P × 分配系数 × 性格防御系数`,母星分配系数 0.6,外围星体均分 0.4。D 决定实例化时防御建筑与驻军的规模缩放,并被轨道轰炸削减(见战斗节)。
- 扩张检查(每 6 游戏时):按性格的目标筛选规则挑一个中立星体,`征服成本 = 400 × 该星体与本势力最近 heldBody 的跳数`(跳数按 `02` 邻接图最短路计算,路径可穿越任何势力或玩家的疆域——太空通行自由,但占领目标只能是中立星体)。`P > 征服成本`(商盟要求 `P > 成本 × 2`)则占领:P 扣减成本,星体归入 heldBodies,L3/L4 即刻可见(疆域染色 + 旗帜)。势力不攻击其他势力的星体(锁定,见 `01` 不做清单),也不直接抢走玩家已控制的星体——与玩家的冲突走"摩擦事件"与袭击(见扩张型行为)。
- 初始值:三家 P 均为 300,T 均为 1.0。
- 步调参考(标准难度默认种子的推演,校准 BalanceSim 用):赤旗约第 14 日占燧砾带、约第 28 日占苍卫、约第 38 日占灼岩——对玩家出生星形成三面合围;商盟约第 17 日占雾卫后基本停手;静默会永远只有眠霜。

### 性格参数表(初始值)

| 参数 | 星贸商盟(贸易型) | 赤旗军团(扩张型) | 静默会(封闭型) |
|---|---|---|---|
| growthMult | 1.0 | 1.3 | 1.0 |
| techMult | 1.0 | 0.8 | 1.6 |
| 扩张目标筛选 | 仅贸易价值星体(燧砾带、雾卫)中未被占者,且 P > 成本 ×2 才动手 | 距玩家出生星跳数最近的中立星体优先(同距取成本低者;距离与成本都相同时取轨道序更高者,保证苍卫先于灼岩) | 永不扩张 |
| 母星防御 D 基准 | ×1.0 | ×1.2 | ×2.5 |
| 主动攻击 | 从不 | 战争状态下周期袭击 | 从不(报复防御极强) |
| 贸易开放 | 报价单 + 保税区 + 稀有条目 | 仅战时勒索/停战赎金 | 不贸易 |
| 独有资源 | 菌金胞(温菏) | 绯铀(赤峦) | 超导蓝矿 + 相变凝胶原浆(眠霜) |
| 封锁科技分支 | 生物精炼 / 星际物流网 | 快堆动力 / 集群战术 | 超导输电 / 相变装甲 |

### 三种性格的行为脚本(每星图刻依序评估,只列真实分支)

**星贸商盟(贸易型)**:

1. 若玩家已建通讯阵列且 attitude ≥ 0 且无有效报价单 → 生成报价单(3 买 3 卖,含菌金胞卖单;每 12 游戏时刷新)。
2. 每笔完成的交易:attitude +2;连续 5 游戏日无交易:attitude -1/日(商人的冷淡)。
3. attitude ≥ 60 时解锁稀有条目(轨道货轮成品、殖民者合同、孢子疫苗、铂族砂小批量——给和平路线一条获取穿甲弹材料与灯塔材料的通道)。
4. 被玩家攻击:立即禁运(报价单撤销),attitude -40,stance = 紧张;不派兵报复。
5. 扩张检查按参数表(极少发生,只为贸易站)。

**赤旗军团(扩张型)**:

1. 扩张检查逢查必扩,目标 = 距玩家出生星尘壤跳数最近的中立星体(默认局面下依次为燧砾带、苍卫、灼岩,然后向巨蔚系推进)。这个筛选规则就是"会撞上你"的机制保证:赤旗的疆域必然朝玩家家门口生长。
2. 当其占领的星体与玩家任一区域所在星体邻接时:stance 至少升为紧张,每 3 游戏日发出一次"边境通牒"事件(索要星币或资源,金额 = P × 0.2)。
3. 玩家拒绝通牒 2 次或先动手 → stance = 战争。战争状态:每 72–144 游戏时(随机)向玩家防御评分最低的区域发起一次袭击(见战斗节),袭击强度 = `clamp(P × 0.05, 8, 40)` 折算为战斗蛛数量,分 1–3 波,提前 24 游戏时给出预警(通讯阵列在则显示波次构成)。
4. 玩家可付赎金停战(金额 = P × 0.5,stance 回紧张,90 游戏日冷却内不再接受赎金)。
5. attitude 只降不升(除停战 +10),不存在与赤旗的贸易繁荣线。

**静默会(封闭型)**:

1. 永不扩张、永不贸易、不响应通讯(外交面板只显示一行冷淡的自动应答)。
2. T 增长最快;其母星实例化时的基地建筑层级按公式(`层级 = clamp(floor(T), 1, 4)` 且不低于玩家当前最高解锁层级),防御 D ×2.5。
3. 玩家舰船进入眠霜轨道:警告一次;着陆非军事载荷:驱离(载荷退回轨道并 attitude -10);军事着陆:立即全防御接战。
4. 唯一的主动行为:每 30 游戏日向全星系广播一条加密谜语(风味内容,深空望远镜可解码为眠霜的部分基地布局情报——给进攻玩家的侦察渠道)。

### 行为差异验收(BalanceSim 场景,进 CI)

- F1(商盟):默认种子 60 游戏日沙盘,玩家脚本在第 10 日建成通讯阵列并保持 attitude ≥ 0:断言"第 15 日前存在有效报价单"且"全程 0 次商盟袭击"。
- F2(赤旗):默认种子 60 游戏日:断言"第 40 日前赤旗 heldBodies ≥ 4"且"其中 ≥ 1 个与玩家出生星尘壤邻接"(按其目标筛选规则,默认局面下依次拿下燧砾带、苍卫、灼岩,撞上玩家是必然事件)。
- F3(赤旗战争):脚本拒绝通牒 2 次:断言"进入战争后 144 游戏时内发生首次袭击"且"袭击强度在 [8,40] 内"且"预警提前量 = 24 游戏时"。
- F4(静默会):60 游戏日:断言"heldBodies 恒等于 1"且"T ≥ 其余两家均值 × 1.3"。
- F5(懒实例化确定性):同一存档同一星体实例化两次(离开再返回),基地布局哈希一致,且第一次被玩家摧毁的建筑在第二次仍是废墟。
- F6(占领收益):脚本化攻占眠霜:断言"结算界面出现超导输电/相变装甲二选一"、"选择后对应配方进入玩家配方库且另一分支永久标记不可得"、"眠霜的超导蓝矿与相变凝胶矿脉对玩家采矿机可用"。

## 懒实例化

- 平时:势力星体只有摘要数据(P 份额、D、独有资源产能、层级 T)。L3/L4 显示疆域、旗帜、按 T 估算的基地规模示意图标。
- 触发实例化:玩家载具进入该星体轨道,或侦察卫星入轨,或军事着陆。
- 生成:从"性格 × 规模档(小/中/大,按 P 份额)"的布局模板库(每性格 3 档,共 9 套人工模板)实例化,随机性由 `hash(游戏种子, factionId, bodyId)` 驱动——同一局内重访结果逐格一致(F5 验收)。商盟基地有货场与灯火,赤旗基地有兵营与雷达,静默会基地有高墙与晶塔阵——模板本身就是性格叙事。商盟母星模板必含护盾穹顶(附庸条约的先决流程依赖它,见附庸节)。
- 差分持久化:玩家造成的破坏、掠夺、占领状态入存档;区域离开 1 游戏日后实例退化回摘要 + 差分。
- 势力基地不跑生产模拟:其"产出"始终由沙盘公式表达。实例化只服务于观感与战斗。

## 战斗(轻量,自动接战)

- 单位:战斗蛛(玩家与势力同源模型,数值差异来自装备件与势力 T)。指令只有三种:驻守(点位)、巡逻(两点)、集结(跟随集结旗)。无微操、无编队技能。
- 防御建筑:围墙(阻挡+耐久)、哨戒炮(动能,耗弹药)、激光塔(耗电,可拦流星)、护盾穹顶(罩半径 12 格,耗电,挡首轮弹幕)。
- 防御战(玩家被袭):预警 24 游戏时 → 波次从区域边缘进入 → 自动接战 → 击退或指挥核心被摧毁(失去区域:建筑变废墟,幸存人口撤往最近己方区域)。防御评分 = 炮塔 DPS 折算 + 墙体系数 + 驻守战斗蛛,UI 常驻显示,袭击目标选择用它(赤旗打最弱区域)。
- 进攻战(玩家打势力星体):
  1. 轨道阶段(可选):发射搭载轨道穿甲弹的火箭轰炸,每发使该星体 D -10%,下限 40%(弹药昂贵:铂催化网材 + 高阶电路)。
  2. 强袭着陆:III 型火箭 + 强袭舱(24 战斗蛛)着陆 → 星体实例化 → 自动攻坚,玩家可下达三类指令与撤退。
  3. 胜利条件:摧毁对方指挥核心 → 进入占领结算。失败(全灭)则 D 回升 10%,势力 attitude -20。
- 战斗掉落:战斗记录仪(军情数据核原料,见 `04`)。

## 占领结算(收益必须具体,禁止数值贴纸)

摧毁势力指挥核心后弹出结算界面,三项收益逐条落地:

1. **星体归属**:该星体转为玩家所有,原基地变为可拆解废墟(拆解返还材料),登陆区可正常建设。
2. **独有资源**:该星体的独有资源矿脉从"势力专营"转为玩家可采——矿脉是真实存在于区域地图上的实体,此前玩家的采矿机对其不可用,占领后可用(F6 验收)。
3. **封锁科技分支二选一**:从该势力的两条分支中选一条永久解锁;未选的分支档案焚毁,本局永久不可得(结算界面明文警告)。选择解锁的是新配方、新建筑、新能力,没有任何一项是纯数值加成。

母星被占后该势力进入"残部"状态:沙盘停止成长,残余 heldBodies 变为中立可自由夺取,报价单/袭击等行为全部停止。

### 六条封锁分支(每条 5 节点,节点 = 配方/建筑/能力)

**超导输电(静默会)**:超导线材(配方)→ 超导电网塔(建筑:跨区域输电、零损耗)→ 超导电池阵(建筑:容量 2000kWh)→ 磁约束节点(建筑:核反应堆输出 +50% 的邻接增效器)→ 轨道能束(能力:向同星体轨道平台无线供电)。

**相变装甲(静默会)**:相变凝胶精炼(配方)→ 相变装甲板(配方)→ 重型城墙(建筑:耐久 ×4)→ 装甲战斗蛛(配方:战斗蛛装备件)→ 热汲护盾(建筑:护盾穹顶升级型,吸收伤害转化为热能发电)。

**生物精炼(商盟)**:菌金催化(配方族:聚合物链产率 +50% 的催化剂投入品)→ 菌木速生架(建筑:菌木可离温菏栽培)→ 蛋白高塔(建筑:食物产能 ×3 的垂直农场)→ 生态穹顶(建筑:士气 +10 区域光环)→ 孢子疫苗(配方:免疫孢子雾)。

**星际物流网(商盟)**:轨道货轮(载具配方)→ 自动报价单(能力:与商盟残部以外的中立保税区自动交易)→ 行情雷达(能力:贸易面板显示未来 3 张报价单预告)→ 保税仓(建筑:出售价 +10%)→ 航线保险(能力:航线货损全额星币补偿)。

**快堆动力(赤旗)**:绯铀精炼(配方)→ 紧凑快堆(建筑:400kW、2×2 占地)→ 核电池(配方:免电网的便携电源件,机器人续航 ×2)→ 同位素加热棒(建筑:极寒星体全区域体温豁免)→ 核动力上面级(火箭部件:转移时间 ×0.67)。

**集群战术(赤旗)**:蜂群协议(能力:战斗蛛编组上限 12 → 24)→ 自爆蛛(单位配方)→ 干扰无人机(单位配方:使敌方炮塔索敌 -50%)→ 前线装配巢(建筑:敌方区域边缘可展开的战地工坊)→ 震荡炮(建筑:范围击退炮塔)。

## 附庸(仅商盟,战斗的替代结局)

对商盟母星的进攻战中,若玩家在摧毁指挥核心前先打掉其护盾穹顶,可在外交面板发起"护国条约":商盟保留温菏,每游戏日向玩家进贡 20 菌金胞 + 500 星币(经自动货轮送达),报价单永久保留且价格优惠 10%;玩家不得在温菏驻军;玩家再次攻击商盟则条约废止且商盟永久禁运。附庸星体计入"星系霸权"胜利条件的 8 星计数。赤旗与静默会无附庸选项(性格使然,锁定)。

## 外交界面(固定动词,无自由谈判)

每势力面板显示:态度值、立场、实力对比条(P 与玩家军事评分)、该势力可用的交互动词。商盟:提议交易 / 请求殖民者合同 / (战时)求和。赤旗:支付通牒 / 宣战 / 支付赎金停战。静默会:发送问候(仅获得自动应答,风味)。全部动词的先决条件与后果在本文档上文均已定义,UI 不引入新机制。
