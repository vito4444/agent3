# 10 Steam 发行

本文档覆盖 Steamworks 集成范围、构建与上传管线、商店素材、本地化与 QA、Demo、发售检查单与用户动作项。对应里程碑 M8。

## Steamworks 集成范围

- 库:Steamworks.NET,UPM git 引用并锁定 release tag(计划撰写时最新为 2025.163.0,对应 Steamworks SDK 1.63;来源:github.com/rlabrecque/Steamworks.NET releases)。
- 初始化与重启保护(`SteamAPI.RestartAppIfNecessary`)、覆盖层兼容验证(UI Toolkit 界面下手动验证覆盖层弹出)。
- 云存档:Steam Auto-Cloud 配置存档目录(不改代码),排除自动存档轮换槽以控制配额,保留手动槽与日档。
- 富状态(Rich Presence)4 态:建设中(第 N 日)/ 深空转移中 / 遭遇袭击 / 终局建造中。
- 统计 6 项:累计游戏日、发射次数、配方解锁数、占领星体数、击退袭击数、贸易成交额。

## 构建与上传管线

- CI 门 3(手动触发):Unity 批处理构建 win64 + linux64 → 版本号 `major.minor.patch+sha` → steamcmd 按 `steam/app_build.vdf` 上传。
- 分支策略:`internal`(每次门 3)→ `beta`(播测轮)→ `default`(发售)。
- Demo 独立 App/Depot,同管线复用。
- 需要用户提供的 Secret:Steam 合作方账号构建凭据、AppID(正式版与 Demo 各一)、`UNITY_LICENSE`、Sentry DSN(可选)。缺失时对应任务标注"阻塞待用户",不静默跳过。

## 本地化与 QA

- 语言:zh-CN(源)+ en。流程:字符串冻结(M8-T4)→ 翻译 → 伪本地化回归(0 硬编码)→ 双语言全流程冒烟。
- QA 矩阵:Windows 10/11 + Ubuntu LTS + Steam Deck(Proton,以"可运行、可读档、帧率 ≥30"为口径,不承诺 Verified)。
- 播测:Steam Playtest 功能两轮(M8-T9 后),每轮收集固定问卷(前 30 分钟流失点、教学卡点、性能)并出报告;问卷与报告入库 `docs/plan/reviews/`。
- 崩溃报告:Sentry;无 DSN 时本地日志落盘并在报错弹窗提供打包按钮。

## 发售检查单(M8-T12 逐项走查)

1. 正式名称定稿与商标/重名查验(用户动作;《星壤》/Starsoil 为占位)。
2. 定价与区域定价(用户动作)。
3. 内容评级问卷(Steamworks 内置,用户账号操作)。
4. 商店页面双语发布并通过 Valve 审核(素材 + 文案 + 页面预览三查)。
5. 成就、云存档、富状态在 beta 分支实测通过。
6. 发售构建 = 通过全部 CI 门与 soak 的那一个 sha,锁定后只允许热修复分支。
7. 发售日运营:已知问题清单公开帖、热修复通道(beta 分支先行)、首周崩溃率与差评关键词监控责任人(用户决策)。
